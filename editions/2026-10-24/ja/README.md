# エミー・ネーター数学論文集 — 日本語訳

エミー・ネーターの論文1–43、M. Deuring筆録の1929/30年冬学期講義「超複素量の代数」、H. Kapfererの論文とE. Noetherの補遺、文献目録および書評・書籍等の一覧を収録する。不変式、イデアル、体、代数および表現論を扱う。
